# Extras (EDA и промежуточные материалы)

Эта ветка содержит дополнительные материалы по данным и исследованию датасета.
Основной код проекта и воспроизводимый пайплайн подготовки данных находятся в ветке `main`.

## Содержимое ветки

### notebooks/
EDA-ноутбуки для анализа и проверки данных:
- `notebooks/EDA.ipynb` — первичный обзор источников и структуры данных
- `notebooks/EDA_10k.ipynb` — анализ финального подмножества (10k) и проверка статистик (частоты ингредиентов и т.п.)

### data/
Папка предназначена для хранения промежуточных и raw-данных, используемых в EDA.
Полный исходный датасет RecipeNLG (несколько GB) в репозиторий не добавляется.

## Как пользоваться
- Для просмотра EDA: открыть ноутбуки из `notebooks/`
- Для получения финального формата данных под RAG см. ветку `main` и скрипты в `scripts/`.
